# Bundled reference artwork

Created for this repository with the built-in `image_gen` tool on September 27, 2026. These files are **source artwork, not QR codes**. The runtime does not call image generation services. The code renderer embeds the payload separately and verifies its output. The generated source files are included under this repository's MIT license.
